**Sombra Heat** is an original open-world crime game set in Puerto Sombra, a coastal city of named buildings, a park with a pond, working docks and a long beach. You play Mara Voss, a fixer-driver working six story chapters — pickups, a stolen Marlin GT, a checkpoint run against the clock, a bank ledger heist, guarded crates and one last vault score — while traffic flows, pedestrians wander and flee, and the Patrulla answer a five-star wanted level with pursuit cruisers, foot officers and a busted meter. Between jobs you can run taxi fares, hunt twelve glass buoys, brawl or buy into a pistol at the Armería, and watch the day turn from dawn gold to lamplit night. It is a top-down 2D canvas game in vanilla JavaScript ES modules — no libraries, no build step, no network — with a HUD and minimap, start and pause screens, localStorage saves, and fully synthesised WebAudio sound.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080
